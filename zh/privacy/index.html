隐私与 Cookie

我们是谁

本网站属于 Cappadocia Vista Tours（TÜRSAB 17102，土耳其内夫谢希尔格雷梅）。有关个人信息的任何问题，请写信至 cappavistatours@gmail.com。

浏览网站时

浏览本网站无需提供姓名、邮箱，也无需注册。网站放在托管服务上（目前为 GitHub Pages）。与所有网站一样，该服务为了向您发送页面，会看到您的 IP 地址。

表单与 WhatsApp

点击表单上的按钮后会打开 WhatsApp，您填写的内容（姓名、日期、人数、感兴趣的行程）会成为一条写好的消息，由您自己发送。在您点击按钮的同时，这些信息也会保存到我们自己的预订面板中，以便我们跟进您的咨询。发送 WhatsApp 消息后，我们会看到您的电话号码、WhatsApp 名称和您写的内容，并用来回复您、安排您的预订。WhatsApp 和 Instagram 有各自的隐私规则。

Cookie 与访问统计

我们使用 Google Analytics 了解有多少人访问网站、浏览了哪些页面。只有在您选择“同意”后才会开始统计。同意后，Google 会在您的浏览器中写入 Cookie（名称以 _ga 开头），访问信息会发送给 Google。我们不使用广告 Cookie。您可以随时通过每个页面底部的“Cookie 设置”链接更改决定。选择“不同意”后，这些 Cookie 会被删除。

我们自己的访问统计

为了了解网站的使用情况，一条简短的访问记录也会发送到我们自己的面板：页面语言、您来自哪个网站或广告（仅网站名称）、设备类型（手机、平板或电脑）、您的时区（用于估计国家）、您浏览到页面的哪个位置、停留时间，以及是否点击了 WhatsApp 按钮或表单按钮。这项统计不使用 Cookie，也不在您的设备上保存任何内容。我们不保存您的 IP 地址。为了把您同一天打开的页面关联起来，您的 IP 地址和浏览器名称会与每天更换的随机值混合，且无法还原。到了第二天，我们就无法认出您。这些记录在 400 天后删除。这些信息不会发送给 Google，而是保存在我们租用的服务器上的面板中。

保存在您设备上的内容

您选择的语言和 Cookie 决定保存在您的浏览器中，这样每次访问时不必再次询问。它们不是 Cookie，只留在您的设备上。

价格

为了显示最新价格，您的浏览器会读取我们的姊妹网站 travel-cappadocia.com 上公开的价格表。此时不会向该网站发送 Cookie 或表单信息。与任何网络连接一样，对方可以看到您的 IP 地址。

您的权利

您可以询问我们持有您的哪些信息，并要求更正或删除。这些权利载于土耳其《个人数据保护法》（KVKK，第 6698 号法律）；对于来自欧盟的访客，还载于 GDPR。只需写信至 cappavistatours@gmail.com 即可。
